# Life’s Big Adventure

A family life-path board game for phones, in the spirit of the classic spin-the-wheel children’s game (college vs job, cars with family pegs, payday, houses, kids, loans). It is an original game — not a Hasbro product.

## Play on a phone

On this Mac, double-click **Play Life Adventure.command**, or open the folder in a browser.

GitHub repo: https://github.com/yodamoney1-tech/lifes-big-adventure

On iPhone Safari: **Share → Add to Home Screen** so it opens like an app.

## How to play

1. 2–4 players, one phone, pass it round. Tick **CPU** for a computer player.
2. Flick the wheel with a finger (a tiny tap is ignored — it wants a real spin).
3. First choice: **uni** ( £50K loan, better jobs ) or **a job today**.
4. Paydays pay your salary. If you *land* on payday, kids cost £5K each, then you choose to **pay off loans** or **skip** (interest).
5. STOP spaces (graduation, wedding, house, retire) halt you for a big choice, then you spin again.
6. Richest net fortune at the end wins: cash + house − loans + family bonuses.

Saved games live in the phone’s browser (Continue on the title screen).
